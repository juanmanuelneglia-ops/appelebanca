# Bancoagrícola Demo

App demo inspirada en Bancoagrícola: sitio público + E-Banca con login simulado.

## Arranque

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Credenciales E-Banca

- Usuario: `cliente`
- Contraseña: `demo123`

## Qué incluye

- Home con hero, accesos rápidos y segmentos
- Páginas de productos (cuentas, tarjetas, créditos, etc.)
- Login protegido con cookie de sesión
- Dashboard, cuentas, movimientos y transferencias (localStorage)
